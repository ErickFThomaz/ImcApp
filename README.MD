# ⚖️ IMC App

App mobile que calcula o IMC e guarda o histórico dos cálculos. Projeto final da disciplina de desenvolvimento mobile na **UNG** (Universidade Guarulhos).

## ✨ O que ele faz

- 🧮 Calcula o IMC a partir do peso e da altura e mostra a faixa
- 📜 Guarda o histórico dos cálculos

## 🚀 Rodando

Roda só no celular (Android ou iPhone). A versão web está desativada.

```bash
npm install
npx expo start
```

Leia o QR code com o app **Expo Go** no celular.

## 🗂️ Estrutura

```
src/
├── Main.tsx        # tela de cálculo
├── History.tsx     # histórico
├── Calculate.ts    # fórmula e faixas
└── Context.tsx     # estado compartilhado
```
